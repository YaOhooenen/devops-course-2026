# Сравнение Git и SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
В Git ветка — это просто указатель на коммит (40 байт), создаётся за секунду. В SVN ветка — это копия всей папки проекта, занимает много места и времени.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет. SVN — централизованная система, коммит идёт на сервер. Без сети можно только редактировать файлы.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
В госсекторе/банках с жёстким контролем доступа, в старых проектах (legacy), при работе с большими бинарными файлами.
